Este es un proyecto realizado con WordPress para las prácticas del Grado Superior.

Proyecto a realizar: creación de una plantilla de WordPress desde Cero con base en un sitio web creado en etapas anteriores.

Estructura del sitio web:

4 páginas (Inicio, Sobre mí, Blog y Contacto).

Estructura del tema:

- `style.css`: Estilos del tema con diseño limpio y responsive.
- `functions.php`: Registro de menús y sidebar.
- `header.php`, `footer.php`, `index.php`, `home.php`, `page.php`, `single.php`: Plantillas base para la estructura del sitio.
- `screenshot.png`: Captura visual del tema.
- `sidebar.php`: Sidebar dinámica con soporte para widgets.
- `readme.md`: Descripción general del proyecto.
- `documentacion.pdf`: Capturas y explicación visual de la web creada.

 Funcionalidades implementadas

-  Tema WordPress desde cero.
-  Menú de navegación horizontal y centrado.
-  Estilos personalizados con CSS.
-  Sidebar dinámica para widgets.
-  Página de blog con posts.
-  Página de contacto con formulario.
-  Responsive básico.eada.
